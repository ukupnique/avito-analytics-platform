# Avito Analytics Platform

# https://avipanel.ru/

Платформа для аналитики объявлений Avito, работы с сообщениями и автоматизации.
Реализованы авторизация, управление сессиями, подключение Avito, синхронизация
объявлений и отображение статистики в личном кабинете.

## Стек

- **Backend:** Python 3.12, FastAPI, Pydantic 2, pydantic-settings.
- **База данных:** PostgreSQL 16, SQLAlchemy 2, asyncpg, Alembic.
- **Авторизация и шифрование:** PyJWT, pwdlib с Argon2id, cryptography/Fernet.
- **Интеграция:** официальный API Avito через HTTPX, OAuth Authorization Code.
- **Интерфейс:** HTML, CSS и JavaScript; раздаётся через FastAPI без отдельной сборки.
- **Запуск:** Gunicorn, Uvicorn, Docker Compose, Caddy для HTTPS в production.
- **Проверки:** pytest, pytest-asyncio, HTTPX MockTransport, Ruff; Node.js для frontend-тестов.

## Возможности

- Регистрация по email и паролю; хранение хеша пароля.
- Access JWT и refresh-токены; в БД сохраняются только хеши refresh-токенов.
- Независимые сессии для разных входов и проверка их состояния при обращении к API.
- Ротация refresh-токенов с защитой от повторного использования и одновременных запросов.
- Выход из текущей сессии с прекращением доступа по связанным токенам.
- Формы входа и регистрации, приветственная страница и восстановление входа при перезагрузке вкладки.
- Подключение Avito через OAuth с одноразовым state, шифрование токенов и автоматическое обновление доступа.
- Синхронизация профиля и всех доступных страниц объявлений; сохранение объявлений в PostgreSQL без дубликатов.
- Карточки объявлений из локальной БД, пагинация и ручное обновление из Avito.
- Просмотры, контакты и избранное за выбранные даты; быстрые периоды: сегодня, 7 и 30 завершённых дней по Москве.
- Сортировка всех сохранённых объявлений по статистике, по возрастанию или убыванию; объявления без данных — в конце.

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/health` | Состояние API |
| `POST` | `/api/v1/auth/register` | Регистрация |
| `POST` | `/api/v1/auth/login` | Вход и выдача пары токенов |
| `GET` | `/api/v1/auth/me` | Текущий пользователь |
| `POST` | `/api/v1/auth/refresh` | Обновление токенов |
| `POST` | `/api/v1/auth/logout` | Выход из сессии; HTTP 204 без тела |
| `POST` | `/api/v1/avito/connect` | Получить ссылку авторизации Avito |
| `GET` | `/api/v1/avito/callback` | Завершить OAuth-подключение |
| `GET` | `/api/v1/avito/accounts` | Подключённый аккаунт без секретных токенов |
| `POST` | `/api/v1/avito/profile/sync` | Синхронизировать профиль и ID пользователя Avito |
| `GET` | `/api/v1/avito/items` | Получить страницу объявлений из Avito |
| `POST` | `/api/v1/avito/items/sync` | Сохранить одну страницу объявлений |
| `POST` | `/api/v1/avito/items/sync/all` | Синхронизировать все доступные страницы |
| `GET` | `/api/v1/avito/items/stored` | Прочитать сохранённые объявления с пагинацией |
| `POST` | `/api/v1/avito/items/stats` | Получить дневные счётчики выбранных объявлений |
